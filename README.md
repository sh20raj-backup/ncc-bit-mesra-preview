# NCC BIT Mesra — Website Preview

An independent, responsive website concept for **3 Jharkhand Composite Technical Company, NCC, BIT Mesra, Ranchi**.

- **Preview URL:** https://sh20raj.github.io/ncc-bit-mesra-preview/
- **Status:** Concept preview; pending official unit/institute approval.
- **Stack:** Single-file HTML, CSS and vanilla JavaScript. No build step.

## Features

- NCC-inspired institutional masthead and navy, gold, red and blue colour system.
- Responsive layout with mobile navigation.
- Historical timeline based on the unit's “Brief History” document provided by the requester.
- Historical event archive with category filters and FAQs.
- Source links to BIT Mesra, NCC Directorate Bihar & Jharkhand, and NCC India.

## Verification and permissions

- This is **not represented as an official NCC or BIT Mesra website** and must not be presented as officially approved until the unit/institute grants permission.
- Current leadership, official contact details, 2026–27 enrolment information, current training schedules and present-day statistics were not verified and are intentionally not invented.
- Certificate and event figures are historical report-period figures.
- The archival photo is remotely hosted by BIT Mesra; confirm reuse permission before public launch.
- Gallery tiles that say “replace with approved unit photos” are conceptual graphics, not depictions of real events.
